# Фоновая музыка

Положи сюда треки `.mp3`, `.m4a`, `.wav` или `.ogg` — Монтажёр (№ 61) тихо подложит один из них под каждую серию.

Только музыка, на которую у тебя есть права: своя, купленная по лицензии или из библиотек
с разрешением на коммерческое использование. Чужая музыка — частая причина блокировки роликов.

Папка пустая — серии выходят без музыки, только голоса.
