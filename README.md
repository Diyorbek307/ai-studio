# AI-студия

Агенты, которые каждый день делают короткую серию мультсериала для Instagram Reels:
придумывают сюжет, пишут сценарий на узбекском, рисуют кадры, озвучивают, монтируют,
проверяют качество и присылают ролик на согласование. «Одобрить» — и ролик уходит в Instagram.

Студию можно продавать компаниям: у каждого бренда свой сериал и маскот, у каждой компании —
**личный кабинет** с сериями на согласование, тарифом и счетами, а у владельца студии — пульт со всеми клиентами.

Первый сериал — **Bozor Seriali**: мыльная опера на базаре (Qovun opa, Anor, Somsa aka, Non bobo, Sabzi).
Библия сериала — `series/bozor-seriali.json`, картинки героев и мест — `series/assets/bozor-seriali/`.

## Быстрый старт (демо, без ключей)

Нужны Node.js 22.6+ и ffmpeg.

```bash
npm install
```

```bash
npm run build
```

```bash
npm run studio -- new
```

Через ~20 секунд в `data/episodes/<id>/final.mp4` появится ролик 1080×1920 с субтитрами:
герои базара в своих местах, говорящий герой подпрыгивает в такт реплике, камера медленно едет.
Без ключей сценарий — заглушка, а голос — тишина.

## Бесплатный старт: один ключ Gemini

Ключ `GEMINI_API_KEY` (aistudio.google.com → Get API key) включает настоящую студию за $0 за серию:

| Часть | Чем делается | Цена |
|---|---|---|
| Мозг: идеи, сценарии, хуки, проверка | Gemini Flash (`GEMINI_TEXT_MODEL`) | бесплатный тариф Google |
| Голоса героев на узбекском и русском | Gemini TTS (`GEMINI_TTS_MODEL`), у каждого героя свой голос и манера | бесплатный тариф Google |
| Кадры и анимация | перекладка (`cutout`) из картинок героев и мест, прямо на сервере | $0 |

У бесплатного тарифа Google есть лимиты запросов в минуту и в день — на 1–3 серии в день их хватает.
Картинки и видео Gemini (Nano Banana, Omni Flash) платные и включаются отдельно: `GEMINI_MEDIA=on`.

**Картинки героев.** Перекладка собирает кадр из картинок: герой — PNG с прозрачным фоном (белый фон уберётся сам),
место — вертикальная картинка. Загружаются во вкладке «Бренды» → «Картинки для перекладки». Пока картинки нет,
студия рисует цветную заглушку с именем героя. Нарисовать героя достаточно один раз — дальше все серии бесплатные
и герой одинаковый в каждой серии.

**Где нарисовать один раз.** Удобно в чате Claude с подключёнными MCP-коннекторами (например, Higgsfield),
в Gemini или в Grok: попросите «маскот бренда в полный рост, прозрачный фон, вертикально» и загрузите PNG в студию.
Сама студия на сервере MCP не вызывает — ей нужны обычные API-ключи; MCP-коннекторы работают в чате.

## Платные движки: какие ключи нужны

Скопируй `.env.example` в `.env` и заполни. Каждый ключ включает свою часть — остальное остаётся бесплатным или в демо-режиме.

| Ключ | Сервис | Что включает |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude | лучший мозг студии: идеи, сценарии, хуки, промпты кадров, проверка роликов, маскоты брендов |
| `GEMINI_API_KEY` | Gemini | бесплатный мозг и голоса; с `GEMINI_MEDIA=on` — кадры (Nano Banana 2.1) и видео (Omni Flash) |
| `XAI_API_KEY` | Grok | кадры и видео Grok Imagine; точная стоимость приходит в ответе |
| `HIGGSFIELD_KEY_ID` + `HIGGSFIELD_KEY_SECRET` | Higgsfield | кадры (Soul) и видео (Kling 3.0) |
| `FAL_KEY` | fal.ai | кадры (Flux) и видео (Kling) |
| `AZURE_SPEECH_KEY` + `AZURE_SPEECH_REGION` | Azure Speech | голоса героев на узбекском, русском, английском |
| `TELEGRAM_BOT_TOKEN` + `TELEGRAM_ADMIN_CHAT_ID` | Telegram | пульт одобрения для студии и бот для клиентов |
| `IG_USER_ID` + `IG_ACCESS_TOKEN` + `PUBLIC_BASE_URL` | Instagram Graph API | публикация и статистика собственного сериала студии |

Режим «Авто» берёт первый подключённый платный движок: Grok → Higgsfield → Gemini → fal.ai, а без них — бесплатную перекладку.
Движок можно выбрать для каждой серии в окне «Новая серия» или флагом `--engine`.
Видео-движки просят видео без звука: голоса героев делает Azure или Gemini TTS, чтобы они звучали одинаково из серии в серию.

### Telegram

1. Создай бота у @BotFather и возьми токен → `TELEGRAM_BOT_TOKEN`.
2. Напиши своему боту `/start`.
3. Открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, найди `"chat":{"id": ...}` → `TELEGRAM_ADMIN_CHAT_ID`.

Студии бот присылает ролики с кнопками ✅ Одобрить, 🔁 Переделать, 🗑 Отклонить и понимает `/new`, `/daily`, `/status`, `/clients`, `/budget`, `/stats`.
Клиенты подключают бота из своего кабинета («Настройки» → «Подключить Telegram» → код) и получают серии с кнопками
✅ Одобрить и ✏️ Попросить правки; `/new <задание>` заказывает серию. Чужим бот не отвечает.

### Instagram

Нужен профессиональный аккаунт Instagram (Business или Creator), приложение Meta с правами
на публикацию контента и статистику, и долгоживущий токен доступа.
Instagram скачивает ролик по ссылке, поэтому сервер студии должен быть доступен из интернета: `PUBLIC_BASE_URL`.
Если токен получен через вход Instagram, а не Facebook, поставь `IG_GRAPH_HOST=graph.instagram.com`.

Сериал клиента публикуется **только в Instagram клиента** (ключи — в карточке клиента, «Изменить»), никогда в аккаунт студии.
Без Instagram одобренный ролик помечается «готов к ручной публикации».

## Студия для компаний: кабинет клиента

| Адрес | Кто видит | Что там |
|---|---|---|
| `/` | все | сайт студии: как это работает, тарифы, заявка (приходит владельцу в Telegram и во вкладку «Клиенты») |
| `/login` | все | вход: владелец — `admin` + `STUDIO_ADMIN_PASSWORD`, клиент — почта + свой пароль |
| `/invite/<ссылка>` | клиент | одноразовая ссылка на 7 дней: клиент задаёт пароль и попадает в кабинет |
| `/app` | после входа | пульт студии или кабинет клиента — зависит от того, кто вошёл |

**Как подключить компанию.** «Бренды» → «Новый бренд» (Дизайнер маскотов № 29 собирает сериал) →
«Клиенты» → «Новый клиент»: бренд, контакт, почта-логин, тариф, кто согласует → «Ссылка в кабинет» — отправить клиенту.

**Тарифы** (`src/plans.ts`, те же, что на сайте): Пилот $150 — 5 серий за 7 дней; Старт $290 — 12 серий в месяц;
Бизнес $590 — 30; Сеть $1200 — 60. Счёт выставляется сам в начале каждого периода, оплату отмечаешь кнопкой «Оплачен».
Переделка серии по правкам не тратит новую серию из тарифа.

**Автопилот.** Ежедневный запуск делает каждому активному клиенту столько серий, чтобы тариф расходовался ровно
по периоду (не больше 2 в день). Серии, заказанные клиентом, тоже засчитываются. Клиент на паузе серий и счетов не получает.

**Кто согласует** (настройка клиента):
- *Студия, затем клиент* (по умолчанию): студия смотрит первой, «Одобрить и отправить клиенту» → клиент одобряет → публикация.
- *Только клиент*: готовая серия сразу уходит клиенту.
- *Только студия*: как для собственного сериала.

Правки клиента возвращают серию студии: сценарист учитывает их, студия проверяет новый вариант и снова отправляет клиенту.
Студия может «Одобрить за клиента», если он ответил по телефону. Вся история решений видна в карточке серии,
а действия — в журнале во вкладке «Клиенты».

**Что видит клиент:** только свой сериал; серию — только после того, как её передала студия (до этого — «в работе у студии»
и прогресс); без расходов, движков и внутренних заметок контролёра. Вкладки: Серии, Ваш сериал, Тариф и счета, Настройки.

**Безопасность.** Пароли — scrypt; приглашения и коды хранятся хешем; сессия — подписанная HMAC cookie
(`HttpOnly`, `SameSite=Lax`, `Secure` при https), смена пароля выкидывает старые сессии; ограничение попыток входа;
POST только со своей страницы (проверка `Origin`). Данные клиентов — `data/clients.json`, `data/invoices.json`
(права 600), заявки — `data/leads.jsonl`, журнал — `data/audit.jsonl`.

## Как устроен конвейер

Продюсер (№ 99) ведёт каждую серию по шагам. Результат каждого шага сохраняется в
`data/episodes/<id>/episode.json`, поэтому после ошибки или паузы серия продолжается с того же места.

| Шаг | Агент | Результат |
|---|---|---|
| idea | № 7 Генератор идей | 5 сюжетов, выбран лучший (с учётом статистики и задания) |
| script | № 12 Сценарист | 3–5 сцен, реплики на узбекском + перевод |
| hook | № 13 Мастер хуков | первые 2 секунды и текст на экране |
| shots | № 21 Дизайнер персонажей, № 23 Хранитель внешности | канон внешности героев, промпты кадров |
| keyframes | № 35 Генератор кадров | `keyframes/s1.png` … (перекладка или платный движок) |
| voice | № 51 Актёр озвучки | голоса героев и раскладка реплик по времени |
| clips | № 42 Аниматор | `clips/s1.mp4` … |
| edit | № 61 Монтажёр | `edited.mp4`: клипы, голоса, музыка из `music/` |
| subtitles | № 63 Субтитровщик | `final.mp4`, `subs.srt` |
| qa | № 71 Контролёр качества | проверка файла и кадров; при браке — одна автоматическая переделка |
| approval | № 80 Пульт одобрения | ролик студии или клиенту — по настройке клиента |
| — | № 81 Публикатор | Reels в Instagram бренда после «Одобрить» |
| — | № 91 Аналитик | цифры роликов → выводы для Генератора идей |

Каждый агент отвечает строго по JSON-схеме (structured outputs у Claude, `responseFormat` у Gemini).
У Claude включена серверная подстраховка (`fallbacks: "default"`).

## Команды

```bash
npm run studio -- help
```

| Команда | Что делает |
|---|---|
| `new [сериал] [--brief …] [--engine …]` | новая серия (по заданию, нужным движком) → на одобрение |

| `run <id>` | продолжить эпизод с места остановки |
| `approve <id>` / `redo <id> "правки"` / `reject <id>` | решения студии |

| `clients` | клиенты: тариф, серии за период, неоплаченные счета |
| `client-add --brand … --email … --contact … [--plan …] [--approval …]` | подключить компанию к её бренду |
| `invite <id клиента>` | ссылка-приглашение в кабинет |
| `daily [сериал]` | ежедневный цикл; без сериала — вся студия и автопилот клиентов |
| `serve` | сайт, кабинеты, Telegram-бот и расписание |
| `engines` / `budget` / `agents` | движки / расход за сегодня / агенты |
| `preview [папка]` | превью без сервера: пульт, кабинет клиента и сайт с демо-данными |

## Деньги

- `DAILY_BUDGET_USD` — дневной лимит. Студия считает расход каждого платного вызова в `data/costs.jsonl`;
  когда лимит исчерпан, серия встаёт на паузу и продолжается на следующий день.
- Бесплатный старт (Gemini + перекладка) расхода не пишет. Claude считается по фактическим токенам,
  платные картинки, видео и голоса — по ценам из `.env`: сверь их с текущими ценами сервисов.

## Сервер и деплой

```bash
npm run serve
```

Сайт — `http://localhost:8080`, кабинет — `/app`. Без `STUDIO_ADMIN_PASSWORD` студия открыта только локально
(для разработки); в production без пароля владелец войти не сможет.

На Render: `render.yaml` создаёт Docker-сервис с диском `/data` под ролики, сериалы, клиентов и счета.
Секреты заполняются в панели Render. Диск есть только на платных тарифах; без него данные пропадают при деплое.

## Свой сериал

Скопируй `series/bozor-seriali.json` под новым именем, поменяй героев, локации, рубрики и правила,
затем `STUDIO_SERIES=<имя>` или `npm run studio -- new <имя>`. Или «Новый бренд» в пульте — сериал соберёт Дизайнер маскотов.
Голос героя: `voice.azure` (`uz-UZ-MadinaNeural`, `uz-UZ-SardorNeural`), `voice.gemini` (Kore, Puck, Charon, Leda…)
и `voice.style` — манера речи для Gemini TTS.
