# AI-студия

Агенты, которые каждый день делают короткую серию мультсериала для Instagram Reels:
придумывают сюжет, пишут сценарий на узбекском, рисуют кадры, озвучивают, монтируют,
проверяют качество и присылают ролик тебе в Telegram. Ты нажимаешь «Одобрить» — ролик уходит в Instagram.

Первый сериал — **Bozor Seriali**: мыльная опера на базаре (Qovun opa, Anor, Somsa aka, Non bobo, Sabzi).
Библия сериала — `series/bozor-seriali.json`.

## Быстрый старт (демо, без ключей)

Нужны Node.js 22.6+ и ffmpeg.

```bash
npm install
```

```bash
npm run build
```

```bash
npm run studio -- new
```

Через ~20 секунд в `data/episodes/<id>/final.mp4` появится ролик 1080×1920 со звуком и субтитрами.
Без ключей все сервисы в демо-режиме: сценарий-заглушка, цветные кадры вместо картинок, тишина вместо голоса.
Так можно проверить весь конвейер, не потратив ни цента.

## Настоящие ролики: какие ключи нужны

Скопируй `.env.example` в `.env` и заполни. Каждый ключ включает свою часть — остальное остаётся в демо-режиме.

| Ключ | Сервис | Что включает |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude | идеи, сценарии, хуки, промпты кадров, проверка качества, аналитика |
| `FAL_KEY` | fal.ai | картинки (№ 35) и видео (№ 42); модели меняются в `FAL_IMAGE_MODEL` / `FAL_VIDEO_MODEL` |
| `AZURE_SPEECH_KEY` + `AZURE_SPEECH_REGION` | Azure Speech | узбекские голоса героев (№ 51) |
| `TELEGRAM_BOT_TOKEN` + `TELEGRAM_ADMIN_CHAT_ID` | Telegram | пульт одобрения (№ 80) |
| `IG_USER_ID` + `IG_ACCESS_TOKEN` + `PUBLIC_BASE_URL` | Instagram Graph API | публикация (№ 81) и статистика (№ 91) |

Перед первым запуском с ключом Claude проверь, как звучит узбекский голос и как выглядят кадры:
сделай одну серию и посмотри её целиком.

### Telegram

1. Создай бота у @BotFather и возьми токен → `TELEGRAM_BOT_TOKEN`.
2. Напиши своему боту `/start`.
3. Открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, найди `"chat":{"id": ...}` → `TELEGRAM_ADMIN_CHAT_ID`.

Бот слушается только этот chat id, остальным не отвечает.
Команды: `/new`, `/daily`, `/status`, `/budget`, `/stats`. Под роликом — кнопки ✅ Одобрить, 🔁 Переделать, 🗑 Отклонить.
После «Переделать» бот попросит написать, что исправить, и пришлёт новый вариант.

### Instagram

Нужен профессиональный аккаунт Instagram (Business или Creator), приложение Meta с правами
на публикацию контента и статистику, и долгоживущий токен доступа.
Instagram скачивает ролик по ссылке, поэтому сервер студии должен быть доступен из интернета:
`PUBLIC_BASE_URL` — его адрес (например, адрес сервиса на Render).
Если токен получен через вход Instagram, а не Facebook, поставь `IG_GRAPH_HOST=graph.instagram.com`.

Без Instagram одобренный ролик помечается «готов к ручной публикации» — выкладываешь сам.

## Как устроен конвейер

Продюсер (№ 99) ведёт каждую серию по шагам. Результат каждого шага сохраняется в
`data/episodes/<id>/episode.json`, поэтому после ошибки или паузы серия продолжается с того же места.

| Шаг | Агент | Результат |
|---|---|---|
| idea | № 7 Генератор идей | 5 сюжетов, выбран лучший (с учётом статистики) |
| script | № 12 Сценарист | 3–5 сцен, реплики на узбекском + перевод |
| hook | № 13 Мастер хуков | первые 2 секунды и текст на экране |
| shots | № 21 Дизайнер персонажей, № 23 Хранитель внешности | канон внешности героев, промпты кадров |
| keyframes | № 35 Генератор кадров | `keyframes/s1.png` … |
| voice | № 51 Актёр озвучки UZ | `voice/*.mp3` и раскладка реплик по времени |
| clips | № 42 Аниматор | `clips/s1.mp4` … |
| edit | № 61 Монтажёр | `edited.mp4`: клипы, голоса, музыка из `music/` |
| subtitles | № 63 Субтитровщик | `final.mp4`, `subs.srt` |
| qa | № 71 Контролёр качества | проверка файла и 4 кадров; при браке — одна автоматическая переделка |
| approval | № 80 Пульт одобрения | ролик тебе в Telegram |
| — | № 81 Публикатор | Reels в Instagram после твоего «Одобрить» |
| — | № 91 Аналитик | цифры роликов → выводы для Генератора идей |

Канон внешности героев Дизайнер пишет один раз и сохраняет в библию сериала,
а Хранитель внешности дословно подставляет его в каждый кадр — так герои не «плывут» от серии к серии.

Каждый агент Claude отвечает строго по JSON-схеме (structured outputs).
Включена серверная подстраховка (`fallbacks: "default"`): если фильтр безопасности ошибочно отклонит
запрос, Claude сам повторит его на запасной модели. Модель по умолчанию — `claude-opus-5-5` (`CLAUDE_MODEL`).

## Команды

```bash
npm run studio -- help
```

| Команда | Что делает |
|---|---|
| `new [сериал]` | новая серия → на одобрение |
| `list` / `show <id>` | список эпизодов / всё об эпизоде |
| `run <id>` | продолжить эпизод с места остановки |
| `approve <id>` | одобрить и опубликовать |
| `redo <id> "правки" [--from шаг]` | переделать (по умолчанию со сценария) |
| `reject <id>` | отклонить |
| `design [--force]` | Дизайнер персонажей: канон внешности |
| `stats` | статистика Instagram и выводы |
| `daily` | ежедневный цикл: статистика → выводы → новые серии |
| `serve` | сервер, панель, Telegram-бот и расписание |
| `budget` / `agents` | расход за сегодня / список агентов |

## Деньги

- `DAILY_BUDGET_USD` — дневной лимит. Студия считает расход каждого вызова в `data/costs.jsonl`;
  когда лимит исчерпан, серия встаёт на паузу и продолжается на следующий день.
- Claude считается по фактическим токенам. Картинки, видео и голос — по оценкам из `.env`
  (`IMAGE_COST_USD`, `VIDEO_COST_PER_SEC_USD`, `TTS_COST_PER_CHAR_USD`): сверь их с текущими ценами сервисов.
- Самая дорогая часть — видео: 3–5 клипов по 5–10 секунд на серию.

## Сервер и деплой

```bash
npm run serve
```

Панель управления — `http://localhost:8080` (логин `admin`, пароль `STUDIO_ADMIN_PASSWORD`).
Там видно все серии, видео и кнопки одобрения. `DAILY_AT=09:00` — ежедневный запуск по времени `STUDIO_TZ`.

На Render: `render.yaml` создаёт Docker-сервис с диском `/data` под ролики и библию сериала.
Секреты заполняются в панели Render. Диск есть только на платных тарифах; без него ролики пропадают при деплое.

## Свой сериал

Скопируй `series/bozor-seriali.json` под новым именем, поменяй героев, локации, рубрики и правила,
затем `STUDIO_SERIES=<имя>` или `npm run studio -- new <имя>`.
Поле `voice.azure` у героя — имя голоса Azure (`uz-UZ-MadinaNeural`, `uz-UZ-SardorNeural`),
`rate` и `pitch` делают голоса разными.
